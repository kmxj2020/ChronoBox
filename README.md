# 时匣 ChronoBox（Windows）

一款**纯本地**的文件版本历史工具：把任意工作文件夹变成可回溯的「时间盒子」，支持增量去重存储、视觉目录快照、文件级生命周期表格与桌面悬浮归档球。基于 **Electron + TypeScript**，零原生 C++ 依赖，适配 Windows 10/11。

> 当前版本 **v5.1.1**。数据格式与 v4.x 完全兼容，升级不会影响已有项目与历史存档。

## v5.1.0 新增（功能与操作方式）

- **全新「文件」视图（资源管理器式）**：左侧目录树 + 右侧文件列表，双击进目录 / 打开文档；右键可新建文件夹、重命名（`F2`）、移动到其他文件夹、创建副本、移入 `00【Archive】`、删除到系统回收站（`Delete`）。所有操作都严格限制在项目根目录内。
- **单元格级检视**：表格视图里**单击**单元格看版本信息，**双击**看「这个文件在这一版发生了什么」——所在版本、大小、内容指纹、完整路径，以及从哪移动到哪 / 复制来源，底部可展开该文件的完整操作轨迹。
- **新增「移动」与「复制」两种状态**：同内容但换了文件夹判定为**移动**（青色），与另一份仍存在的文件字节级一致判定为**复制**（粉色），不再一律显示成「重命名」。
- **隐藏文件**：右键文件名即可隐藏不关心的文件；表格工具栏用一个眼睛按钮一键显示/收起全部隐藏项。
- **表格列数可设**：设置 → 常规与悬浮窗 → 表格视图显示，可选「自动适配窗口」或固定 4~8 列。固定列数时展开右侧详情栏不会少显示列，只会把列宽挤压变窄。
- **对比视图自绘下拉**：版本列表改成「标题左对齐、时间右对齐」的两栏，长标题不再被时间戳挤成一团。
- **悬浮球重做**：径向渐变 + 有色光晕 + 内高光替代原来的硬白描边；贴边时变成真正贴住屏幕边缘的半圆把手。

## v5.0.0 更新亮点（界面与体验重构）

- **全新设计系统**：五层语义化表面、字号/圆角/间距/动效阶梯、统一焦点环与「减少动画」降级；7 套主题（跟随系统 / 明亮 / 暗黑 / 春夏秋冬）各自拥有完整色板。
- **底部状态栏**：同步状态、文件数、存档数、磁盘占用与节省、自动存档状态、快捷键入口、版本号常驻一行。
- **左右分栏可拖拽调宽**（双击复位），宽度与上次停留的视图都会记住。
- **右侧详情栏按视图自适应**：设置 / 归档箱这类全局页自动让位，回到数据视图自动还原。
- **命令面板重做（Ctrl+K）**：13 条分组命令 + 模糊匹配 + 键位提示，可键盘全程操作。
- **快捷键速查表（?）**、**撤销恢复**（恢复存档后 12 秒内可一键退回）、**完整键盘层**（Ctrl+1…6 / F5 / Ctrl+Shift+T / Ctrl+Shift+F / Esc）。
- **表格视图列宽自适应**（不再把版本标题截断）、**时间轴去噪重绘**、**关系图节点重构**、**对比视图空态化**、**设置页图标统一为线性 SVG**。
- **滚动位置保持**：后台自动刷新不再把时间轴弹回顶部。
- 修复 7 处既有缺陷（列宽常量错位、原生滚动条回退、四季主题 token 缺失、设置页宽度死锁等），详见 [`docs/升级报告-v5.0.0.md`](docs/升级报告-v5.0.0.md)。

## 核心功能特性

1. **一键存档（时间盒子）与本地增量存储**
   - 底层采用 **SHA-256 内容寻址存储 (CAS) + zlib 压缩**，所有文件历史 100% 存储在项目本地隐藏目录 .chronobox/ 中。
   - 相同内容零冗余复制，结合 `size + mtime` 元数据缓存，对 Office、CAD、PDF、图片等二进制文件扫描与存档均保持高性能。
   - 内置忽略规则自动过滤 Office 临时锁文件（`~$*`）、`*.tmp`、`Thumbs.db`、`desktop.ini` 等干扰文件，并支持自定义通配符规则。
2. **一键切换/恢复存档与自然分支**
   - 点击任意历史存档即可将整个文件夹精准回溯到当时状态（恢复被删文件、回滚修改、清理多余文件及残留空目录）。
   - 切换前自动检测未保存改动，默认支持「先创建自动保护存档再切换」，彻底杜绝误操作丢数据。
   - 回到任意历史存档后继续编辑并存档，系统自动以该历史节点为父节点分叉出新分支，无需学习 Git 分支命令。
   - 支持**单文件精准恢复**与**整存档导出到外部目录**。
3. **双视图自由切换：时间轴视图 + 关系视图（思维导图 DAG）**
   - **时间轴视图**：高信息密度时间线卡片，清晰展示当前版本标记、变更统计（`+新增 ~修改 -删除`）、颜色标签与工作区实时变更提醒。
   - **关系视图**：交互式 SVG 思维导图（有向无环图），以不同分支色条和平滑贝塞尔曲线呈现每次方案迭代与分叉脉络，支持画布拖拽平移、滚轮缩放与双击快速切换。
4. **存档差异对比（文件清单 + 行级文本 Diff）**
   - 支持**任意两个历史存档**之间或**当前工作区与历史存档**之间的实时差异对比。
   - 文本文件内置 LCS 逐行差异高亮；二进制文件展示大小与 SHA-256 哈希变化对比。
5. **极简 3 色存档标签与检索筛选**
   - 极简三色体系：**红（重要里程碑）/ 黄（待定方案）/ 绿（已定稿）** 3 色标签，支持按标签筛选及按标题、备注、文件名即时搜索。
6. **Mini 模式（Mini 悬浮条 + Mini 呼吸小圆点）与 Windows 系统托盘**
   - **Mini 悬浮条**：置顶半透明胶囊窗口，实时显示当前项目变更数，支持一键存档与自由拖拽。
   - **Mini 呼吸圆点**：44×44px 桌面悬浮呼吸圆点（绿色=已同步，琥珀色呼吸灯=有未存档变更），单击展开悬浮条、双击回到主窗口。
   - 支持 Windows 系统托盘驻留、全局快捷键（`Ctrl+Shift+S` 一键存档、`Ctrl+Shift+M` 切换 Mini 模式）、定时自动存档、孤立对象空间回收 (GC)、浅色/深色主题与简体中文/English 双语切换。

## 快速开始（Windows 10 / 11）

### 前置环境
- [Node.js 18 LTS 或更高版本](https://nodejs.org/)

### 方式一：双击一键启动
直接双击项目根目录的 **`一键安装并启动.bat`**，脚本将自动完成依赖安装、TypeScript 编译并启动桌面应用。

### 方式二：命令行运行
```powershell
npm install
npm run build
npm start
```

### 打包为 Windows 安装包 (.exe) 与便携版
双击 **`一键打包Windows安装包.bat`** 或执行：
```powershell
npm run dist:win
```
打包完成后可在 `release/` 目录获取 NSIS 安装包（`时匣ChronoBox-<版本>-x64-Setup.exe`）与免安装便携版（`时匣ChronoBox-<版本>-Portable.exe`）。

### 运行核心引擎自动化测试
```powershell
npm test
```

## 项目架构

```text
src/
├── core/                  # 零外部依赖的纯 Node.js + TypeScript 核心引擎
│   ├── types.ts           # 统一类型契约
│   ├── ignore.ts          # 内置与自定义通配符忽略规则
│   ├── objectStore.ts     # SHA-256 内容寻址存储 + zlib 压缩 + 完整性校验 + GC
│   ├── scanner.ts         # 带 stat-cache 优化的目录扫描器
│   ├── diffEngine.ts      # 快照差异与 LCS 行级文本 Diff
│   ├── dagLayout.ts       # 思维导图式关系视图 DAG 布局算法
│   ├── fileMatrix.ts      # 文件级演进矩阵（含重命名/移动/复制/归档/删除判定）
│   ├── repository.ts      # 时间盒子存档、回溯、分支、单文件恢复、导出
│   ├── workspaceManager.ts# 多项目工作区与配置持久化
│   └── watcher.ts         # 防抖实时监听与定时自动存档调度器
├── main/                  # Electron 主进程（三态窗口管理、IPC、系统托盘与全局快捷键）
├── preload/               # 安全 contextBridge 预加载桥接
└── renderer/              # 主窗口与 Mini 悬浮窗口 UI（时间轴、SVG 关系图、Diff、设置）
    ├── styles/
    │   ├── tokens.css     # v5 设计令牌：表面/文字/主色/阴影/圆角/字号/动效 + 7 套主题
    │   ├── main.css       # 主窗口样式（骨架/控件/视图/弹窗/命令面板）
    │   └── mini.css       # 桌面悬浮球与 Mini 条样式
    └── scripts/           # 各视图渲染器与交互逻辑

tools/                     # 开发辅助：基于 CDP 的截图与冒烟测试
├── capture.mjs            # 启动真实窗口 → 按脚本切换视图 → 逐屏截图
├── smoke.mjs              # 全交互冒烟 + 运行时错误采集
└── steps.json             # 截图脚本（视图/主题/弹窗序列）
```
