关于时匣与使用说明书

一、三层本地历史保护（临时历史 + 时间盒子 + 00【Archive】）

  • 临时历史文件（未存档草稿）：两次正式存档之间，每次保存/修改/重命名文件都会在后台自动留存临时快照。在「表格视图」单击文件名或最右侧「实时（未存档）」方格，右侧栏即显示第 1、2、3… 次修改记录并支持一键回退；点击正式存档后自动清空。
  • 时间盒子（正式快照）：存放在项目内隐藏目录 .chronobox/，采用 SHA-256 增量去重压缩，支持随时切换回溯、分支探索与差异对比。
  • 00【Archive】归档箱：存放在项目内可见目录 00【Archive】/YYYY-MM-DD/，100% 保留原生格式与结构，拖入桌面悬浮球即可收走旧文件（按住 Ctrl 为复制留档），支持一键放回原位。

二、表格视图（默认首页 · 文件级追踪）

  • 每文件占一行，重命名文件自动保持在同一行追踪；自动联动 00【Archive】 区分「已归档」与「直接删除」；默认开启「仅看当前分支」排除旁支干扰。
  • 视口精准展示 6 个版本列：普通滚轮上下浏览文件，按住 Shift + 滚轮左右平滑查看历史版本；文件变更后自动滚到最右侧「实时（未存档）」列，并支持「跳到最新 →」。
  • 直接编辑文档：双击左侧文件名直接用系统默认软件打开编辑；右键文件名可打开文档、在资源管理器中定位或置顶关注。

三、桌面悬浮球 / Mini 条（独立常驻 + 三色实时感知）

  • 独立开关：开启「悬浮窗」后与主窗口互不冲突，后台也能常驻显示；悬停精简展示最多 3 行信息（项目名、状态、当前文档/目录）。
  • 三色感知（250ms 极速刷新）：绿色 = 已添加且已存档同步；橙色 = 有未存档变更或待创建首个存档；紫色 = 当前文件夹/桌面/文档未添加为项目。
  • 防误触操作：双击悬浮球仅对已添加项目一键存档（紫色未添加状态禁用双击自动添加）；右键悬浮球可将当前文件夹添加为项目、存档、打开主窗或隐藏悬浮窗。

四、项目安全管理与恢复模式

  • 父子项目双选保护：添加含现有子项目的父文件夹时，弹窗可选「独立管理（自动排除子项目，互不干扰）」或「升级合并为父级项目（软归档子项目保留历史）」。
  • 外部重命名无损重连：同级目录下重命名文件夹会自动通过仓库 repoId 无损重连；跨盘移动可一键「重新定位项目文件夹」。
  • 双模式恢复与防错：默认「覆盖恢复到当前工作文件夹」（切换前自动检测 Word/Origin 写锁并保护未存档修改），也支持「恢复到全新独立文件夹」对照查看；支持一键拉起 Beyond Compare 深度对比。
